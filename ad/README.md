# 상상의문 웹 리뉴얼 — 세일즈 광고 (아뱅 주도)

방탈출 본사 **상상의문 대표/점주에게 보내는 리뉴얼 광고**입니다. 설명형 제안서가 아니라, 심리를 건드려 *리뉴얼하고 싶게* 만드는 광고/세일즈 랜딩(단일 HTML).

- **열기**: `ad/index.html` 브라우저로. 이미지는 `ad/assets/`(실제 상상의문 테마 포스터·히어로).
- **디자인**: 다크 베이스 + 강팀 보라→분홍을 '빛/단서'로(방탈출=어둠·문·열쇠). Crowny Class 토큰 계열.

## 심리 레버 (아뱅)
- **손실회피** — "닫는 순간 옆 가게로 갑니다" / 빈 슬롯 = "오늘 사라지는 돈"
- **경쟁·질투** — "옆 동네는 폰에서 5초면 예약 끝"
- **지위·정체성** — "31개 테마 만든 사장님이 낡은 예약표 뒤에 숨어 있습니다"
- **사회적 증거** — "손님은 '예약 가능한 곳'이 아니라 '예약하기 편한 곳'을 고릅니다"
- **낮은 부담** — "사장님이 할 일은 없습니다, 그대로 옮겨 드립니다" / 무료 진단 CTA

## 흐름
히어로(폰에서 마지막으로 열어본 게 언제?) → 일격(이탈) → 숨은 무기(할인 슬롯) → 거울(포스터 월) → **Before/After 드래그 슬라이더**(낡은 예약표 ↔ 모던 모바일 카드, 광고 클라이맥스) → 숫자(6·31·1) → 사회적 증거 → 그대로 이사(6지점) → CTA → 마무리("문만 열면 됩니다").

## 근거 / 한계
- 실데이터: 6개 지점·31개 테마·예약금 2만원·조조/심야/막타임 할인 (운영 사이트에서 추출, `doorlove1234-coder/sangsangDoor` 자료).
- ⚠️ 현재 운영 사이트(상상의문.com)는 이 환경의 네트워크 정책상 직접 접속 불가 → "낡았다"를 단정 증거로 들이대지 않고 점주가 스스로 느끼게 하는 심리 카피로 처리. Before/After의 'BEFORE'는 레거시 예약표를 형상화한 *연출 목업*(실제 캡처 아님).
- 발송 전: 실제 연락처·진단 CTA 링크만 연결하면 됨.
