나는 무엇을, 왜 만들었나

🖥️ 무엇을 만들었나

학원 강사가 학생 수십 명을 화면 하나로 관리하는 교실 관리 프로그램.
좌석·화면 모니터링·파일 전송·퀴즈·상담·결제까지 — 교실의 모든 상호작용을 앱 하나로.

🖥️
앱 화면 이미지 자리
(같은 폴더에 강사앱화면.jpg)

🎯 왜 만들었나

자료는 USB·카톡, 출석은 종이, 화면 단속은 발로, 시험은 출력 — 프로그램 대여섯 개 + 수작업의 연속이었습니다. 강사 한 명이 학생 수십 명을 케어하면서도 수업 자체에 집중할 수 있게, 흩어진 도구를 하나로 모았습니다.

원칙 — "있으면 좋은 기능"이 아니라 "없어서 아팠던 기능"만 만든다.

기능별 의도 ①

기본 기능1~5

기능없었을 때의 불편학생 케어선생님 케어심리 · 실제로 좋아진 점
1. 파일 전송USB 돌리기, 카톡 단체방에 자료 뿌리기 — 누가 받았는지 알 수 없음자기 자리에서 바로 받음, 자료 분실 없음수십 명에게 클릭 한 번, 수신 여부 확인"자료 못 받았어요" 손드는 일이 사라져 수업 흐름이 안 끊김
2. 1:1 채팅질문하려면 손들고 모두 앞에서 말해야 함조용히 개인적으로 질문 — 부끄러움을 케어수업을 멈추지 않고 개별 응대소심한 학생의 질문 문턱이 낮아져 질문 수 자체가 늘어남
3. 좌석 관리종이 배치도, 결석·자리 변경 수작업 관리내 자리가 명확함, 이름으로 불러줌화면 한 장이 곧 출석부 + 상태판이름을 불러주는 교실 → 소속감. 자리 파악 시간이 0이 됨
4. 효과/포인터"잘했어요"가 말뿐 — 전달이 약함화면에 즉각 칭찬 이펙트 — 작은 성취가 보임클릭 한 번으로 리액션작은 보상의 반복이 참여 동기를 만듦 (도파민 설계)
5. 공지사항칠판·말로 공지 → 잊어버림, 반복 설명언제든 화면에서 다시 확인한 번 쓰면 전원에게 전달"그거 언제까지였죠?" 질문이 눈에 띄게 감소

Part 3 · 직접 만들기 ①

🎮 게임 만들기 — 브라우저에서 바로 도는 첫 작품

메모리 카드 짝맞추기 게임을 만듭니다. 설치도 서버도 필요 없이, 파일 하나를 더블클릭하면 브라우저에서 바로 실행 — 첫 성취감이 가장 빠른 코스입니다.

1단계 — 뼈대

  • 게임 규칙을 말로 정리한다 (코딩보다 먼저)
  • AI에게 "4×4 카드 보드"를 요청한다
  • 브라우저에서 열어 카드가 깔리는 것 확인 — 오늘은 여기까지. 한 번에 다 하려고 하지 마세요.

2단계 — 완성·꾸미기

  • 짝 맞추면 사라지기 → 다 맞추면 승리 → 점수·시간
  • 일부러 에러를 만나고 → AI로 푸는 과정 체험
  • 미드저니로 만든 이미지로 카드 디자인
그대로 복사해서 쓰세요 — "카드 16장을 4×4로 깔고, 클릭하면 뒤집히는 메모리 게임을 HTML 파일 하나로 만들어줘. 디자인은 나중에 할 거니까 일단 동작 위주로."
결과물: 친구에게 파일만 보내면 바로 플레이되는 게임. "방금 여러분, 게임 개발자 됐습니다."
Part 3 · 직접 만들기 ②

🌐 웹 만들기 — 인터넷 주소가 생기는 순간

나를 소개하는 포트폴리오 페이지를 만들고, 전 세계에서 접속되는 주소로 공개합니다.

1단계 — 구조

웹은 뼈대(HTML)·옷(CSS)·움직임(JS). AI에게 헤더/소개/프로젝트/연락처 구조를 요청하고 내용만 내 것으로 바꿉니다.

💡 1편에서 만든 게임을 '내 프로젝트'에 링크하세요 — 결과물이 결과물을 부릅니다.

2단계 — 살아있는 기능

방명록·연락 폼을 답니다. 크라우니클래스의 채팅·메모도 결국 "입력 → 저장 → 다시 보여주기" — 규모만 다르지 원리는 지금 이것과 같습니다.

3단계 — 배포

GitHub 저장소에 올리고 GitHub Pages를 켜면 끝.

https://내아이디.github.io
— 무료로 생기는 내 주소입니다.

URL이 생겼다는 건 더 이상 연습이 아니라는 뜻입니다. 이력서에 붙일 수 있는 링크가 손에 남습니다.
Part 3 · 직접 만들기 ③

🚀 앱 제작 + 배포 — Vercel로 세상에 공개

로그인·저장 같은 기능이 도는 진짜 앱을 만들고, Vercel로 한 번에 배포합니다. GitHub에 올리기만 하면 자동으로 배포·갱신되고, 전 세계 어디서나 접속되는 주소가 생깁니다.

1단계 — 앱 만들기

게임·웹에서 배운 사이클 그대로, 규모만 키워 기능이 도는 앱을 AI와 함께 제작합니다.

2단계 — GitHub 연결

코드를 GitHub 저장소에 올리고 Vercel에 연결 — 이제 git에 올릴 때마다 자동 배포됩니다.

3단계 — Vercel 배포

버튼 한 번이면 끝. HTTPS·도메인 연결까지 자동.
내앱.vercel.app 주소가 생깁니다.
