# 상상의문 웹사이트 리뉴얼 제안서 (강팀)

방탈출 본사 **상상의문 대표에게 보내는 신뢰형 리뉴얼 제안서**입니다. 광고가 아니라 **컨설팅 보고서 톤** — 트렌드·개선 방향·기대효과를 근거와 함께 담았습니다.

- **열기**: `proposal/index.html` 브라우저로(인쇄 시 그라데이션→단색 폴백). 이미지는 `proposal/assets/`(실제 테마 자산 예시).
- **디자인**: 강팀 Crowny Class 토큰을 **라이트·프로페셔널 모드**로 — 그라데이션은 표지·마무리 2곳만, 본문은 흰/연회색 + 절제된 보라. 본문 ≥16px, 색대비 보정 반영.

## 구성 (8섹션)
00 표지(+미접속 전제 고지) · 01 요약/목차 · 02 배경·트렌드(2025–26, 출처 포함) · 03 현황 진단(현장 확인 권장 배지) · **04 현재→개선→효과 비교표(심장)** · 05 기대효과(측정 기반 KPI) · 06 추진 일정 타임라인 · 07 진행 방식·신뢰박스 + 규제/접근성 · 08 마무리+연락처

## 강팀 회의 (이 제안서를 만든 사람들)
- **아뱅(마케팅)**: 2025–2026 실제 트렌드 7개(모바일 퍼스트·속도=전환·간편결제·세계관·리뷰·로컬SEO)를 출처와 함께 조사 + 비즈니스 근거 + 정직한 기대효과 표
- **강디(디자인)**: 라이트·프로페셔널 IA + "현재→개선→효과" 6영역 비교표 + 비주얼 토큰 가이드
- **강체크(QA)**: 신뢰박스(책임범위·데이터 처리) + 규제(개인정보·환불·연령) + 색대비 보정

## 정직 원칙 (신뢰의 핵심)
- ⚠️ **현재 운영 사이트(상상의문.com)는 이 작업 환경의 네트워크 정책상 직접 접속·진단하지 못했습니다.** 그래서 '현황'은 단정이 아닌 진단(추정)으로, "현장 확인 권장" 배지를 달았습니다.
- 기대효과는 근거 없는 정밀 수치 대신 **"측정 필요" + 측정법**으로. 목표값은 기준선 측정 후 합의.
- 트렌드 수치는 업계 매체 출처라 **방향만 신뢰·절대값은 참고**임을 명시.
