# 상상의문 웹사이트 리뉴얼 제안서

방탈출 본사 상상의문 대표님께 보내는 웹사이트 리뉴얼 제안서입니다. 트렌드·현재 상태 점검·개선 방향·기대 효과·진행 과정을 담았습니다.

- 열기: `view.html`(이미지까지 한 파일에 내장, 압축 없이 바로 열림) 또는 `index.html`(+`assets/`).
- 구성: 표지 · 제안 요약 · 지금의 흐름(트렌드) · 현재 상태 점검 · 개선 방향(현재→개선→효과 표) · 기대 효과(측정 기반) · 진행 과정 · 진행 방식 · 마무리.

## 작성 원칙
- 사전 진단 단계에서 작성 — 현재 상태는 '확인 필요'로 표기, 정확한 진단은 착수 시 점검으로 확정.
- 기대 효과는 근거 없는 수치 대신 '측정 후 확정' + 측정 방법으로 제시.
- 보내기 전: 연락처 [입력] 칸을 실제 정보로 교체.
